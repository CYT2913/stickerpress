# 印刷与 SVG 规格

本文是 `AGENTS.md` 第 0.3 节的展开版，供印前实现和印厂沟通使用。所有数值都必须能在 SVG 几何里被验证，`forge.py verify` 会逐项复核。

---

## 1. 成品规格

| 项目 | 值 | 说明 |
|---|---|---|
| 成品尺寸 | 148 × 210 mm | A5 竖版 |
| SVG 根元素 | `width="148mm" height="210mm"` | `viewBox` 必须与实际布局一致 |
| 出血 | 0 mm（默认） | kiss-cut 半切台纸，成品即 A5，不需要出血；只有整切工艺才启用出血 |
| 贴纸数量 | 正好 6 枚 | 多一枚少一枚都判不合格 |
| 安全边距 | ≥ 10 mm | 任何贴纸内容和刀线都不得越过 |
| 贴纸最小净距 | ≥ 8 mm | 刀线到刀线的最短距离 |
| 单枚尺寸 | 建议 22–62 mm | 任一方向硬下限 20 mm |
| 有效分辨率 | 400 dpi 基准 | A5 对应约 2331 × 3307 px |

### 为什么默认无出血

kiss-cut 是"半切"：只切贴纸面材，不切底纸。台纸边缘不参与裁切，因此没有整切工艺里"切偏露白"的问题，出血反而会让成品比 A5 大、和标称规格对不上。

若印厂要求整切（die-cut through），再启用出血：`engine/stickerpress/config.py` 的 `bleed_mm` 设为 3.0，画布自动变为 154 × 216 mm，并输出裁切标记。裁切标记**只在 `bleed > 0` 时输出**。

## 2. 刀线规范

| 项目 | 值 |
|---|---|
| 图层 | 独立 `CutContour` 图层（`<g id="CutContour">`） |
| 颜色 | `#FF00FF`（品红专色） |
| 线宽 | **0.25 pt = 0.088194 mm**，代码取 `0.0882 mm` |
| 填充 | `none` |
| 路径 | 闭合（`Z` 结尾） |
| 工艺 | kiss-cut 半切 |

> ⚠️ **单位陷阱**：0.25 pt ≠ 0.25 mm。0.25 mm ≈ 0.7087 pt，比目标粗约 2.8 倍，RIP 可能把它识别成印刷线条而非刀线。本项目曾经踩过这个坑，见 `CHANGELOG.md`。

换算：`0.25 pt × 25.4 / 72 = 0.088194 mm`。

### 刀线形状

- **装配层**（`forge.py`）：保守使用**圆角矩形**刀线。理由是几何完全可验证、必然闭合、不会自交，适合作为交付基线。
- **产线层**（`engine/`）：支持**异形轮廓**——alpha 边界追踪 → 形态学外扩 → RDP 简化 → Bezier 拟合。异形刀线必须通过碰撞与留白验证才能交付。

不得手改导出的 SVG 来"修"刀线，绕过校验的文件一律不算交付。

---

## 3. SVG 自包含要求

- 位图必须以 **data URI** 内嵌（`xlink:href="data:image/png;base64,..."`）；
- 不得引用本地路径或远程 URL；
- 不得依赖系统字体（如需文字，转曲）；
- 判定方法：把 SVG 复制到任意空目录、断网打开，内容必须完整。

---

## 4. 分辨率

有效 dpi 按贴纸在版面上的物理尺寸算：

```
effective_dpi = pixel_width / (width_mm / 25.4)
```

- 基准 400 dpi；
- 低于 300 dpi 装配层会拒绝并报错；
- 报告中记录每一枚的实际 dpi 和最低值。

A5 400 dpi 全幅参考像素：`148/25.4×400 ≈ 2331`，`210/25.4×400 ≈ 3307`。若额外提供 PNG 预览，必须写明它的实际像素与 DPI，不得让印厂误以为预览就是印刷源。

## 5. 自动验收项

`python3 forge.py verify <svg>` 检查：

1. SVG 可解析；
2. 画布尺寸 148 × 210 mm 且与 `viewBox` 一致；
3. 贴纸位图数量 = 6；
4. 存在 `CutContour` 图层；
5. 刀线颜色 `#FF00FF`、线宽 0.0882 mm；
6. 每条刀线闭合；
7. 刀线两两净距 ≥ 8 mm；
8. 全部内容距页边 ≥ 10 mm；
9. 单枚尺寸在 20–62 mm 内；
10. 无外部资源依赖。

**不能自动判定、必须人工复检**的项：

- 有效分辨率是否满足印厂要求（报告给数值，人判断）；
- 内容合规（品牌 / 角色 / 肖像 / 隐私）；
- 跨目录、跨机器打开测试；
- 印厂模板匹配度。

## 7. 印厂差异处理

不同模切厂对刀线命名、出血和文件偏好不一致。默认规范是 `CutContour` / `#FF00FF` / 0.25 pt / kiss-cut。**客户提供印厂模板时以模板为准**，并在交付报告中记录与本默认规范的差异项。常见差异：

| 差异点 | 常见变体 |
|---|---|
| 刀线图层名 | `CutContour` / `Thru-cut` / `Die` / `刀版` |
| 刀线颜色 | `#FF00FF` / 100% Magenta 专色 / 100% Cyan |
| 是否需要出血 | kiss-cut 通常不需要；整切需 3 mm |
| 文件格式 | SVG / PDF（X-4）/ AI |
| 是否要求刀线单独文件 | 部分厂要求刀线与图分离成两个文件 |
