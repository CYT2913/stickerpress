# 用 ChatGPT Plus 跑通这个产品

> 结论先行：**Plus 能跑通，但要走"人工出图 + 本地装配"这条路**。因为 Plus 给的是 ChatGPT 应用内的图像能力，**不含 API 额度**，所以本项目的自动生图 Provider 接不上你的 Plus 订阅。

---

## 1. 先把订阅关系理清

| 说法 | 实际情况 |
|---|---|
| "Codex Plus" 是单独的产品 | ❌ 没有这个独立订阅。Codex 已包含在 ChatGPT Free / Go / Plus / Pro / Business / Enterprise 各套餐里，你开的就是 **ChatGPT Plus 一份订阅** |
| Codex 额度 = 图片额度 | ❌ 两回事。OpenAI 官方说明：ChatGPT 里的图像生成、文件上传、语音各有独立限制，**这些限制不适用于 Codex** |
| Plus 里带 API 额度 | ❌ 官方帮助中心明确写着 Plus **不包含 API**，API 用量单独计费 |

对本项目的直接影响：

- ✅ 你可以用 Plus 在 **ChatGPT 应用里**生成贴纸大图；
- ✅ 你可以用 Plus 里的 **Codex** 把本仓库跑起来（它是编码 Agent，能执行装配命令）；
- ❌ 你**不能**让 `AimeImageProvider` 用你的 Plus 订阅自动生图——那需要 API Key，得在 `platform.openai.com` 单独充值。

所以路线是：**图在 ChatGPT 里人工出，印前在本地自动做。**

---

## 2. 推荐路线：ChatGPT 出图 → 本地装配

这条路零 API 花费，只消耗你 Plus 本来就有的图片额度。全流程已在本仓库实测跑通。

```
ChatGPT App（Plus）           本地（零依赖 / 零网络）
─────────────────            ──────────────────────────
上传照片 + 六宫格提示词
        ↓
下载六宫格大图 PNG  ──────→  engine CLI --sheet
                              背景透明化（真 alpha 直通 / 品红兜底）
                              切分 / 刀版 / A5 排版
                                        ↓
                              forge.py verify 独立验收
                                        ↓
                              可交付 A5 SVG + 原图 + 报告
```

### 第 1 步：在 ChatGPT 里生成六宫格大图

**首选：直接要透明背景。** 现在的 ChatGPT 出贴纸时，导出的 PNG 通常是**真透明**的（预览里那层灰白棋格只是查看器画给你看的底衬，不在文件里）。真 alpha 的边缘质量比任何色度键都好——没有溢色、没有阈值损失，产线拿到就直接用。

```
把这张照片里的主体做成 6 枚卡通贴纸，排成 2 列 × 3 行的六宫格，背景透明（透明 PNG）。

硬性要求：
1. 背景必须是真正的透明通道，不要把灰白棋盘格当成图案画出来。
2. 六枚贴纸之间留出明显的透明空隙，任意两枚不得相接或重叠。
3. 每枚贴纸带 3-4px 的白色描边，主体完整居中，不要被画面边缘裁切。
4. 画面比例 2:3，输出你能给到的最大尺寸。
5. 六枚风格统一：同一套线条粗细、同一套配色。
6. 贴纸上不要出现任何文字、logo、水印、二维码。
7. 主体只保留：<在这里填你要的 6 个元素，例如：狗的开心脸 / 睡觉 / 歪头 / 吐舌 / 打招呼 / 蜷成一团>
```

出图后逐条对照检查，不合格就让它改：

- [ ] 正好 6 枚，彼此不相接（**这一条最关键**：贴纸一旦粘连，切分会把两枚当成一枚）
- [ ] 没有文字、logo、水印
- [ ] 主体没被边缘切到

### 第 1.5 步：花 2 秒确认是真透明还是假透明

肉眼分不出来，因为两者在查看器里都显示棋格。跑一下：

```bash
python3 engine/tools/check_alpha.py ~/Downloads/stickers.png
```

三种结果：

| 结论 | 含义 | 怎么办 |
|---|---|---|
| `真透明，可直通产线` | 有 alpha 通道，透明像素占比正常 | 直接进第 2 步 |
| `疑似假透明（棋盘格被画成了图案）` | 没有 alpha，棋格是画上去的像素 | **必须重出**，否则格子会被印在纸上 |
| `不透明图，但背景是纯品红可走色度键` | 没有 alpha，但背景是纯 `#FF00FF` | 可以用，走色度键兜底 |

工具还会顺手告诉你这张图能切出几枚。**看到 `6/6` 才算稳。**

### 第 1.5b 步（可选兜底）：模型给不出真 alpha 时改用品红

如果反复出图都是假透明棋盘格，或者你用的工具链导出时会把 alpha 拍平，就换成让模型在纯品红上作画，本地再把背景键掉。把上面提示词的第 1、2 条替换为：

```
1. 背景必须是纯品红色 #FF00FF，整幅铺满，不要渐变、不要阴影、不要棋盘格。
2. 六枚贴纸之间留出明显的品红空隙，任意两枚不得相接或重叠。
```

选品红是因为它在 HSV 空间里几乎不会和贴纸主体撞色，且只键掉**与画面边缘连通**的品红像素，主体内部的同色细节不会被误穿孔。代价：主体本身不能大面积用品红或洋红。**这是兜底方案，不是首选**——能拿到真 alpha 就别绕这一圈。

### 第 2 步：分辨率够不够

这是 Plus 路线最容易翻车的地方。印刷按**每枚贴纸自己的像素**算，不是按整张图：

```
有效 dpi = 贴纸像素宽 / (贴纸成品毫米宽 / 25.4)
```

本项目单枚成品在 22–62 mm 之间，按最大的 56 mm 算：

| 目标 | 单枚需要的像素 | 六宫格整图大致需要 |
|---|---|---|
| 300 dpi（及格线，低于此装配层直接拒绝） | ≈ 660 px | ≈ 1700 × 2550 |
| 400 dpi（本项目基准） | ≈ 880 px | ≈ 2300 × 3300 |

**导出时选你账号能给的最大尺寸**。如果拿到的图偏小，装配层会明确报错而不是默默印糊——这是设计如此，别绕过它。

如果单枚只有约 400–600 px，但你接受更小的实体贴纸，可用装配层的 `--target-dpi 300` 自动缩小尺寸。这不会增加图片细节，只是让现有像素覆盖更小的印刷面积；缩小后任一方向不足 20 mm 仍会被拒绝。

### 第 2.5 步：一张一张存，还是 6 张一起存？

ChatGPT 通常两种都给。**优先一张一张存**，理由只有一个但很硬：**分辨率**。

单张导出时，每枚贴纸都能拿到导出上限（比如各 1024×1024）；六宫格整张导出时，那个上限要被 6 枚**平分**（1024×1536 的图，每格只剩 512×512）。实测同一批素材：

| 保存方式 | 素材 | 产线实测最低有效 dpi | 能不能印 |
|---|---|---|---|
| 一张一张存 | 6 × 1024×1024 | **505 dpi** | ✅ 自动验收全过 |
| 六宫格整张存 | 1 × 1024×1536 | **204.8 dpi** | ❌ 低于 300 门槛 |
| 六宫格整张存（大图） | 1 × 2400×3600 | 399.8 dpi | ✅ |

差了约 2.5 倍。**只有当整张导出的分辨率本身够大（≳2300×3300）时，两种才等价。**

单张保存还顺带省掉切分环节：不存在"两枚贴纸挨太近被当成一枚"的风险。走装配层即可：

```bash
python3 engine/tools/check_alpha.py art/*.png --single   # 逐枚自检
python3 forge.py assemble source.jpg --artwork-dir art --rights rights.json \
  --outdir out --target-dpi 300
```

单张保存的三个注意点：

1. **必须正好 6 个文件**，且和来源照片**分开放**。把原图和 6 张贴纸丢在同一个目录，装配层会收集到 7 个文件并报错。贴纸单独放 `art/`。
2. **按文件名字典序排格位**，所以要补零：`sticker_01.png` … `sticker_06.png`。`sticker_1`～`sticker_10` 这种会乱序。
3. **逐枚确认透明**，别只查一张——偶尔会有个别文件导出时 alpha 被拍平。

即便走单张路线，**六宫格整张也建议存一份**：它是风格一致性的对照底稿，也是单张导出出问题时的兜底。

### 第 3 步：本地跑装配

```bash
git clone https://github.com/CYT2913/stickerpress.git && cd stickerpress

# 需要 PIL / numpy / scipy
pip install pillow numpy scipy pyyaml

cd engine && python3 -m stickerpress.cli run /path/to/你的原图.jpg \
  --sheet /path/to/从ChatGPT下载的六宫格.png \
  --no-review \
  -o ../work/out --job-id my-order-001
```

`--sheet` 走 `SheetFileProvider`，**完全跳过生图**，只做本地的抠图、切分、刀版和排版。
`--no-review` 关掉需要联网的 VLM 审核；关掉之后合规裁决会按 `fail_mode: review` 降级为"转人工"，**成品不会被标记为可下单**——这是有意的，内容合规必须你自己肉眼过一遍。

实测输出（用仓库示例素材跑的）：

```
质检：6 张 · 最低 231.5 dpi · 刀版净距 13.45 mm
裁决：⚠️ 转人工复核    可否下单印刷：否
```

这里 231.5 dpi 不达标，是因为示例素材本身像素低。你用 ChatGPT 的大图会好得多。

### 第 4 步：独立验收

```bash
cd .. && python3 forge.py verify work/out/my-order-001/sticker_sheet_A5.svg
```

12 项几何检查，验收器不复用装配器的几何逻辑，两边都错才会漏：

```
[ok] 画布尺寸与 viewBox 一致：148.0×210.0 mm
[ok] 贴纸位图数量：6 张
[ok] 刀线专色与线宽：#FF00FF / 0.0882mm（0.25pt）
[ok] 刀线闭合：6/6 条以 Z 收口
[ok] 刀线最小净距：13.08 mm（门槛 8.0 mm）
[ok] 安全边距：12.44 mm（门槛 10.0 mm）
[ok] 无外部资源依赖：全部位图以 data URI 内嵌
```

## 3. 另一条路：自己切好六张，直接用零依赖装配层

如果你想手工挑选、或者六枚来自不同的几次生成，就跳过 engine，直接喂 6 张透明 PNG 给 `forge.py`。这条路**不需要装任何第三方库**。

```bash
# 1) 权利声明，缺省即拒绝
python3 forge.py rights-template > rights.json   # 按实填写，别留 unknown

# 2) 六张资产单独放一个目录（原图不要放进去，否则会被算成第 7 张）
python3 forge.py assemble /path/to/原图.jpg \
  --artwork-dir /path/to/art \
  --rights rights.json \
  --outdir outputs/order-001 --order-id order-001 \
  --target-dpi 300
```

最后一行仅在需要缩小低像素资产时使用；印刷级资产可省略。装配器只缩小实体尺寸，不重采样位图。

实测（用仓库 `assets/samples/stickers/` 的六张）：

```
刀线净距 : 11.20 mm
安全边距 : 11.60 mm
最低 dpi : 400
自动验收 : 全部通过
```

资产要求见 [`ARTWORK_CONTRACT.md`](ARTWORK_CONTRACT.md)：正好 6 张、真 alpha、命名补零、单独目录。

## 5. 三条路线怎么选

| | ChatGPT Plus 人工出图 | 充 API 额度全自动 | 已有六张资产 |
|---|---|---|---|
| 额外花费 | **0**（用 Plus 自带图片额度） | 按 token 计费，需在 platform.openai.com 单独充 | 0 |
| 每张台纸手工步骤 | 1 次对话 + 1 次下载 | 无 | 无 |
| 批量能力 | 弱，一单一单来 | 强，可脚本化 | 强 |
| 适合 | 试产、小批量、打样 | 稳定接单后 | 设计师自己画 |

**建议**：先用 Plus 这条路把前 10 单跑顺，确认版式、刀线、印厂对接都没问题，再考虑充 API 做自动化。印前的坑（分辨率、刀线单位、净距）比生图的坑贵得多，值得先用低成本方式踩完。

## 6. Plus 的图片额度能出多少张

OpenAI 不公布固定张数，且会动态调整，帮助文档里出现过 "50 images in the last day" 这类提示横幅作为示例——**这是示例不是承诺**，以你账号里实际看到的提示为准。

能确定的是本项目这边的消耗结构：

- **1 次成功出图 = 1 张 A5 台纸 = 6 枚贴纸**（六宫格一次出六枚，已是最省的做法）
- 抠图、切分、刀版、排版、质检、验收全部本地，**不消耗任何额度**
- 调版面、改刀线、换尺寸时用 `--sheet` 复用同一张大图，**零额度消耗**

所以真实产出 ≈ `你当天的可用出图次数 ÷ (1 + 重试率)`，再乘以 6 枚。输入照片干净时重试率约 0.1–0.2；含人物或潜在 IP 时会明显上升。

---

## 7. 别忘了合规

用 Plus 手工出图意味着**你自己就是那道合规闸**。`--no-review` 关掉的是模型审核，不是你的责任。交付前逐枚确认：无品牌 / Logo / 版权角色 / 二维码 / 车牌 / 证件信息，无未授权可识别人物。完整口径见 [`COMPLIANCE.md`](COMPLIANCE.md)。

生成贴纸不等于取得商业使用权。照片的著作权、画面中人物的肖像授权，该确认的还是要确认。
